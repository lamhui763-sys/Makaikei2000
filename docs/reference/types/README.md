# Types & Interfaces

Document public types, interfaces, and schemas here.

## How to add a type

1. Create a file per domain area, e.g. `user.md`.
2. For each type/interface, include: fields, constraints, defaults, examples.

## Template

### TypeName
- Description: ...
- Fields
  - `fieldName`: Type — description
- Example
```json
{
  "fieldName": "value"
}
```
